# Ahmad Romiz — Personal Portfolio

Live site: https://ahmadromiz1.github.io/

Static bilingual portfolio for Ahmad Romiz, currently a Solution Analyst at Bank Mandiri — APD Group, with a responsive light theme, category and technology filters, and project case-study dialogs. The personal photo, professional experience, education, certifications, email, and LinkedIn from the previous portfolio are retained.

## Files

- `index.html`: English portfolio (default landing page).
- `index-en.html`: English alias.
- `index-id.html`: Indonesian portfolio.
- `portfolio.css`: responsive styles, project flows, career timeline, and reduced motion support.
- `portfolio-data.js`: bilingual project details and public repository URLs.
- `portfolio.js`: filtering, native dialog interactions, and current year.
- `assets/profile.jpg`: existing personal profile photo.

Implementation notes and Zentro solutions remain at `/cerita-romiz/`. The root portfolio links directly to those pages. Monitoring and backup details come from the original root portfolio; finance implementation metrics are contextual case-study figures rather than public demo benchmarks.

## Local preview

No build or dependency installation is needed:

```sh
python3 -m http.server 8000
```

Open http://localhost:8000. For links to the Zentro pages, use the live site or serve both repositories with `/cerita-romiz/` mapped to the sibling checkout.

GitHub Pages publishes the root of the `main` branch. Original anchor links `#projects`, `#experience`, `#skills`, `#education`, `#about`, and `#contact` remain available.

Design reference: https://sylvaan.github.io/.
